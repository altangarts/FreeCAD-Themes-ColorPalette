# FreeCAD Themes - ColorPalette
ColorPalette Themes, makes the interface and workspaces more user-focused. It simplifies theme color selection and allows you to apply single-color, dual-color, triple-color, and gradient-color combinations to the entire window.

### ----- This themes are for FreeCAD version ≥ 1.1.0 -----

 ___________________

## ☑️ Theme Selection


#### ✅ Theme Selection 1 :
   - Important for processing theme requirements
   - Installs the ColorPalette theme configuration.
1. Edit ➡ Preference ➡ General ➡ Application ➡ Theme - apply and restart

⤵️
![Ekran görüntüsü 2026-01-29 185701](https://github.com/user-attachments/assets/c9d265f4-c1d1-43f5-b6a6-213d0d414ac5)


#### ✅ Theme Selection 2 :
   - This should be used after "Theme Selection 1" when changing themes
   - Installs without changing your configuration
1. Edit ➡ Preference ➡ Display ➡ UI ➡ Theme Customization ➡ Style Sheet(Advanced) = Theme
2. Edit ➡ Preference ➡ Display ➡ UI ➡ Theme Customization ➡ Overlay Style Sheet = Overlay (Select same name as the theme)

## ☑️ Theme Color Selection:

 
#### ✅ Main Colors and Selection Color,
1. Edit ➡ Preference ➡ Display ➡ UI ➡ Theme Customization


   - "Accent color 1" = Selection background 
   - "Accent color 2" = Top background
   - "Accent color 3" = Middle background
   - "Accent color 3" = Bottom background

⤵️
![Ekran görüntüsü 2026-01-29 1902491](https://github.com/user-attachments/assets/19c2478b-6eb5-4195-8d5c-ae1ded03c14e)

   
 
#### ✅ Font Colors and ready-made theme color combinations
   1. Edit ➡ Preference ➡ Display ➡ ColorPalette ➡ Theme Colors

       - You can change the texts colors by clicking on the color boxes. You can also select one of the preset theme color combinations. To use your own theme color, adjust the "Accent colors" options.

#### ✅ Light Colors and Settings,
   1. Edit ➡ Preference ➡ Display ➡ Light Sources

       - With the ColorPalette configuration lighting settings, objects do not blacken at any angle of view

#### ✅ Shape Appearance Settings,
   1. Edit ➡ Preference ➡ Part/Part Design ➡ Shape Appearance

       - The light and object color are adjusted in the ColorPalette theme settings so that the outlines of the objects are easily visible. The outlines do not disappear in shadow or light

 ## ☑️ Note: 
 
   - Max-Light: #909090
   - Max-Dark: #303030
   - If "Accent color 3" is not applied, it is substituted with other variables (Style Sheet(Advanced), Accent color 1-2 or restart)
   - Color selection suggestion: 'Dark colors' and 'Dark and pale pastel colors'
   - When using "Overlay", darker or a gradient from dark to lighter colors from top to bottom is recommended
